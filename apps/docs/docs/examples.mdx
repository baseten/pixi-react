Each example below runs live in this page, rendered by the `@pixi/react` build these docs were built from. The code is the example's real source: the same files are the routes of the standalone example app in [`apps/examples`](https://github.com/baseten/pixi-react/tree/main/apps/examples), which the repository's browser tests load. The examples use only local assets and no randomness, so every run draws the same frames.

The interactive editors elsewhere in these docs are different: they run in CodeSandbox with the published npm packages, and are labelled so.
