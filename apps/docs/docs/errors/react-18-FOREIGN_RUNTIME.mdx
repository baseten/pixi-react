# `react-18.FOREIGN_RUNTIME`

**A hook was called inside an application of another renderer.** Raised by the React 18 adapters (`@pixi/react-18.0` … `@pixi/react-18.3`). Each `createRenderer` call creates its own runtime with its own registry and roots, and its hooks (`useApplication`, `useTick`, `useExtend`) work only inside an `<Application>` (or `createRoot` tree) of the same runtime.

## Common causes

- A component imports `useApplication` or `useTick` from one renderer module but is rendered by an `<Application>` of another, for example two libraries that each compose their own renderer.
- `createRenderer` is called more than once, for example inside a component or in two modules, so the `<Application>` and the hooks come from different calls.

## How to fix

Call `createRenderer` once, at module level, export its result from one module of your own, and import `Application`, `extend` and every hook from that module:

```ts
// src/pixi-react.ts
export const { Application, extend, useApplication, useTick, useExtend, createRoot } =
    createRenderer({ react: new React18Adapter(), pixi: new Pixi8Adapter() });
```

Then replace any hook import that points to another renderer module with an import from that module.
